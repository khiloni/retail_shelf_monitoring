# Dataset Directory Layout

This folder is used for local datasets, reference images, and video feeds.

## Directory Structure

```
data/
├── reference_shelves/        # Reference images for shelf alignment (e.g., S1.jpg, S2.jpg)
├── demo/                     # Generated by scripts/make_demo_data.py for offline testing
│   ├── shelf_reference.jpg   # Synthetic reference shelf image
│   ├── shelf_stream.mp4      # Synthetic video stream with simulated OOS and misplaced products
│   └── sku_crops/            # Reference crop database organized class-per-folder
├── SKU110K_fixed/            # (Optional) Raw SKU-110K dataset if downloaded locally
│   ├── images/
│   └── annotations/
└── custom_yolo/              # (Optional) Custom YOLO export downloaded from Roboflow
```

## Obtaining Datasets for Full Training

- **SKU-110K**: Automated in `training/colab_train.ipynb` via Ultralytics auto-download on Google Colab / Kaggle.
- **Custom Roboflow Dataset**: Provide your workspace, project, and API key in the Colab notebook config cell.
